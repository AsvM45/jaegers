## Mission and non-negotiable scientific contract
Predict the next-spin payout distribution for every query over **exactly five classes [0,1,2,5,20]**. CSV columns exactly: `query_id,p_0,p_1,p_2,p_5,p_20`. Eight machines share one episode and one query cutoff. Types: steady, balanced, jackpot; conditions: stable, short_history, drift, shared_change. The main kit has 96 train, 96 public validation and 192 test episodes, eight machine queries each: **1536 main test rows**.

Source data are histories of actual payouts with integer ticks, sometimes missing. A missing tick is **unknown**, NOT an observed payout of 0. At prediction tick c, use only rows with **tick < c** for both target and sibling machines, and **only within the same episode**. Exact lag c-2 is not the second-most-recent observed row. Historical as-of training at labeled tick t uses observed payout at t as label, features exclusively from ticks < t. Query signal (-1/0/1) is available at current cutoff but historical signal(t) isn't separately released: do NOT silently fill historical training rows using the final query's signal. Test true condition and target probabilities are hidden.

**Official metric** is squared distance to true 5-class vector, averaged over the 8 machines in each episode and across episodes in each of 4 conditions, normalized by each condition's reference error; average ratios to R; main points = 60/(1+R), adaptation = 40/(1+R) per inspected kit. `check_submission.py --split validation` / `slot_forecasting.rounds` is the official path. A different scoring.py 0–100 diagnostic and train observed-label Brier ARE NOT official points. Public validation true probability vectors have already informed aspects of the champion (SIZE_REGIMES); treat public score as development-exposed, NOT hidden test performance.
